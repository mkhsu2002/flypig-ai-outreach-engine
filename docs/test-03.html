FlyPig AI Outreach Engine / Experiments / 03
Experiment 03 · Canada · Dogfooding + Control

If a strong LLM is already good, what does FlyPig add?

如果裸 LLM 已經很強，FlyPig 到底增加了什麼？

FlyPig used its own framework to find likely Canadian early adopters. Then a fresh high-capability LLM was asked to solve the same business problem without reading the FlyPig method.

FlyPig 先用自己的框架尋找加拿大第一批可能採用者，再讓一個全新的高階 LLM 在完全不讀 FlyPig 方法的情況下處理同一個商業問題。

01

Question and setup

題目與設定

FlyPig run

Who should care about FlyPig first?

誰最可能先需要 FlyPig？

No fixed channel taxonomy was supplied. The framework had to infer the most useful adopter and partner paths from the product itself.

沒有預先指定 Channel Taxonomy，系統必須自己從產品與市場證據推導最值得探索的採用者與合作路徑。

Control run

Fresh naked LLM

全新的裸 LLM

The control could use current web research and its own best judgment, but could not read FlyPig methodology before finishing the substantive work.

Control 可以自由使用 Web Research 與最佳判斷，但在完成主要研究前禁止讀取 FlyPig Methodology。

The strongest hypothesis became service firms that repeatedly perform prospect research, plus AI/CRM implementation firms that could embed the process across multiple clients.

最強的採用者假設變成：會反覆替客戶進行 Prospect Research 的服務公司，以及能把這套流程嵌入多個客戶專案的 AI / CRM Implementation Firm。

The control was very good. It was also broader and more creative around accelerators, communities, training programs, and ecosystem amplifiers.

Control 的表現非常好，而且在 Accelerator、Community、Training Program 與 Ecosystem Amplifier 等方向上，比原本 FlyPig Run 更廣、更有創意。

04

What the comparison actually showed

真正看出來的差異

Naked LLM strength

Excellent one-shot research

單次研究可以非常強

A capable model can form a strong market thesis and produce useful prospects without FlyPig.

能力足夠的模型，本來就能獨立形成很好的市場策略與 Prospect 名單。

FlyPig strength

Required process discipline

把好習慣變成必做流程

Deduplication, evidence checks, persistent rejected history, and skeptical review are required rather than left to the model's discretion.

Dedup、Evidence Check、被排除對象的研究記憶與 Skeptical Review，不再取決於模型「這次有沒有想到」。

FlyPig weakness found

The original search space was too narrow

原本 Search Space 太窄

The control exposed a real gap. FlyPig responded by adding a mandatory Discovery Diversity Check before convergence.

Control 找出一個真正的缺口，因此 FlyPig Core 後來新增 Mandatory Discovery Diversity Check。

05

Final review

最終心得與限制

The conclusion became simpler: FlyPig is not about making the LLM smarter. It is about making good research behavior repeatable across long, stateful business-development work.
結論反而變得更簡單：FlyPig 不是讓 LLM 變聰明，而是讓好的研究行為在長流程、持續狀態的商務開發任務中可以穩定重複。

Limitations

限制

  • The control was one run, not a large repeated benchmark.
  • The two runs formed different GTM theses, so list overlap is not a simple quality score.
  • Public evidence cannot establish real adoption appetite.
  • FlyPig's audit is same-model role separation, not independent-model review.
  • Control 是單次 Run，不是大型重複 Benchmark。
  • 兩邊形成不同 GTM Thesis，名單重疊度不能直接當品質分數。
  • 公開 Evidence 無法證明真正的 Adoption Appetite。
  • FlyPig Audit 仍屬同模型 Role Separation，不是 Independent-model Review。
