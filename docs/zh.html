01

真正的瓶頸不是「找得到公司」，而是知道哪些公司值得你的業務花時間。

Problem 01

想進一個市場，卻連該找哪種角色都不確定

客戶？Distributor？Importer？Integrator？Strategic Partner？一開始找錯角色，後面的開發工作都可能白做。

Problem 02

名單看起來很多，實際查下去卻不適合

品類相似、關鍵字符合都不代表它真的適合。很多公司看起來很像目標，商業角色其實完全不對。

Problem 03

人工研究一多，就開始重複、遺漏與失焦

當名單擴大，重複公司會重新出現、先前判斷會遺失，Qualification 標準也容易慢慢漂移。

常見問題

FlyPig AI Outreach Engine 是什麼？

Open Core 是一套開源的潛在客戶研究與資格判定流程，包含供 LLM 讀取的 Skills、流程規則、Schema 與範本。它在具備即時網頁研究能力的 LLM 或 Agent 中執行，並維護一份 Qualified Prospect Tracker。

開源核心與委託服務有什麼差別？

你可以依 Apache-2.0 授權自行使用 Open Core，不需要安裝 FlyPig 伺服器。委託服務則是由 FlyPig 執行研究、資格判定與審核，交付附有來源證據的潛在客戶追蹤表；範圍與合作條件會在檢視需求後討論。

公開核心會寄送開發信或自動操作 LinkedIn 嗎？

不會。公開流程到 Qualified Prospect Tracker 為止。訊息撰寫、寄信、LinkedIn 自動化、回覆追蹤及後續聯繫執行都不在公開 Open Core 的範圍內。

三項公開實驗能證明什麼？

實驗分別檢查日本市場的商業角色分類、德國市場依據證據修正研究任務，以及加拿大早期採用者探索與裸 LLM 對照。這些是公開案例研究，不代表模型比較優越，也不保證回覆、銷售或採用；各實驗均連結到公開驗證資料。
